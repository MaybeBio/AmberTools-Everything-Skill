# Chapter 15: Constant pH & Redox Potential MD

## Core Commands & Syntax

### Preparing a Constant pH System
```bash
# Edit PDB: rename HIS/HID/HIE -> HIP, ASP/ASH -> AS4, GLU/GLH -> GL4
# Then in LEaP:
source leaprc.constph
x = loadpdb myprotein.pdb
saveamberparm x myprotein.prmtop myprotein.rst7

# Generate cpin file
cpinutil.py -p myprotein.prmtop -igb 2 -o cpin
cpinutil.py -p myprotein.prmtop -igb 2 -states 1 3 0 0 0 1 -o cpin

# For explicit solvent CpHMD (must modify radii for carboxylates):
cpinutil.py -igb 2 -resnames AS4 GL4 -p <tleap_prmtop> -op <new_radii_prmtop>
```

### Running Constant pH MD (Implicit Solvent)
```bash
sander -O -i cph.in -o cph.out -p prmtop -c inpcrd \
    -cpin cpin -cpout cpout -cprestrt cprestrt -r rst7
```
Key mdin: `icnstph=1`

### Running Constant pH MD (Explicit Solvent)
```bash
pmemd.cuda -O -i cph_explicit.in -o cph.out -p new_radii_prmtop \
    -c inpcrd -cpin cpin -cpout cpout -cprestrt cprestrt -r rst7
```
Key mdin: `icnstph=2`

### Analyzing Constant pH Simulations
```bash
# Standard statistics
cphstats -i cpin cpout -o pH_stats.dat

# Cumulative average
cphstats -i cpin cpout --no-calcpka --cumulative \
    --cumulative-out cumulative.dat -n 10000

# Running average (window=10000, interval=2000)
cphstats -i cpin cpout -n 2000 -r 10000 -R running_avg.dat

# Chunk analysis
cphstats -i cpin cpout --chunk 100000 --chunk-out chunk.dat

# Populations
cphstats -i cpin cpout --populations populations.dat

# Conditional probabilities
cphstats -i cpin cpout -c "35:P,52:D" \
    --conditional-output conditional.dat

# Fix pH-REMD cpout files
cphstats --fix-remd reordered cpout.000 cpout.001 cpout.002 cpout.003
```

### Preparing a Constant Redox Potential System
```bash
source leaprc.conste
ceinutil.py -p prmtop -igb 2 -o cein

# For residues that are both pH- and redox-active:
cpeinutil.py -p prmtop -igb 2 -o cpein
```

### Running Constant Redox Potential MD
```bash
sander -O -i credox.in -o credox.out -p prmtop -c inpcrd \
    -cein cein -ceout ceout -cerestrt cerestrt -r rst7
```

### Analyzing Redox Simulations
```bash
cestats -i cein ceout -o redox_stats.dat
cestats --fix-remd reordered.ceout ceout.000 ceout.001 ceout.002 ceout.003
```

### Fix REMD cpout/ceout files (general tool)
```bash
fixremdcouts.py -prefix reordered -couts cpout.000 cpout.001 ceout.000 ceout.001
```

### Finding Reference Energies for New Titratable Residues
```bash
# Serial mode (CpHMD)
finddgref.py -mdexec pmemd.cuda -i mdin -p prmtop -c restrt -cpin cpin

# Parallel mode (pH-REMD)
finddgref.py -do_parallel "mpirun -np 4" -mdexec pmemd.cuda.MPI \
    -ng 4 -groupfile groupfile -target 4.4
```

### cpin file format (generated by cpinutil.py)
The cpin file contains namelist data for each titratable residue:
- `RESNAME`: residue name (AS4, GL4, HIP, LYS, TYR, CYS)
- `RESSTATE`: current protonation state
- `PROTCNT`: proton count per state
- `STATENE`: reference energies for each state
- `CHRGDAT`: charge vectors for each state
- `RESSTATES`: initial protonation states (set by cpinutil.py)

## Common Workflows

### 1. Set Up a Complete CpHMD Simulation
**Step 1:** Edit PDB: rename HIS to HIP, ASP to AS4, GLU to GL4.

**Step 2:** Source `leaprc.constph` in LEaP, load PDB, save prmtop/rst7.

**Step 3:** Generate cpin file with reference energies:
```bash
cpinutil.py -p prmtop -igb 2 -o cpin
```

**Step 4:** For explicit solvent, regenerate prmtop with adjusted radii:
```bash
cpinutil.py -igb 2 -resnames AS4 GL4 -p prmtop -op new_radii.prmtop
```

**Step 5:** Run with `-cpin`, `-cpout`, `-cprestrt` flags:
```bash
pmemd.cuda -O -i cph.in -o cph.out -p prmtop -c inpcrd \
    -cpin cpin -cpout cpout -cprestrt cprestrt
```

**Step 6:** Restart using the cprestrt file as the new cpin:
```bash
pmemd.cuda -O -i cph.in -o cph2.out -p prmtop -c rst7 \
    -cpin cprestrt -cpout cpout2 -cprestrt cprestrt2
```

### 2. Calculate pKa Values from CpHMD
**Step 1:** Run cphstats to get fraction protonated:
```bash
cphstats -i cpin cpout -o pKa.dat
```

**Step 2:** The pKa is computed from the Henderson-Hasselbalch equation:
```
pKa = pH - log((1 - fp) / fp)
```
where fp is the fraction protonated.

**Step 3:** For a more rigorous fit, use the Hill equation across multiple pH values:
```
fd = 1 - fp = 1 / (1 + 10^(n*(pKa - pH)))
```
Fit with your own script to get both pKa and the Hill coefficient n.

### 3. Set Up Constant Redox Potential
**Step 1:** Prepare PDB with HEH residue (heme + axial histidines + cysteines), HIO (backbone histidines), CYO (backbone cysteines), PRN (heme propionates).

**Step 2:** Source `leaprc.conste` in LEaP, load PDB, save prmtop/rst7.

**Step 3:** Generate cein file:
```bash
ceinutil.py -p prmtop -igb 2 -o cein
```

**Step 4:** Run with `icnste=1`, `solve=0.81` (target redox potential in V):
```bash
sander -O -i credox.in -p prmtop -c inpcrd \
    -cein cein -ceout ceout -cerestrt cerestrt
```

### 4. Generate New Reference Energies (finddgref.py)
**Step 1:** Prepare CpHMD input files for the model compound (ACE-X-NME).

**Step 2:** In the cpin file, set `STATENE` to use `DELTAGREF`:
```
STATENE=0.0,DELTAGREF,DELTAGREF,DELTAGREF,DELTAGREF,
```

**Step 3:** Run finddgref.py (serial mode):
```bash
finddgref.py -mdexec pmemd.cuda -i mdin -p prmtop -c restrt -cpin cpin
```

**Step 4:** The program iterates automatically, returning the DELTAGREF value that gives ~50% protonation at the target pH.

**Step 5:** Update Amber source code with the new reference energy so cpinutil.py can use it.

## Reference Tables

### Constant pH variables in &cntrl
| Variable | Description | Values |
|----------|-------------|--------|
| `icnstph` | Enable constant pH | 0=off, 1=implicit, 2=explicit |
| `ntcnstph` | Steps between MC attempts | 5 (implicit), 100 (explicit) |
| `solvph` | Solvent pH | e.g., 7.0 |
| `ntrelax` | Solvent relaxation steps (explicit) | 200 |
| `mccph` | Monte Carlo type | 0=Metropolis, 1=Wang-Landau |

### Constant Redox Potential variables in &cntrl
| Variable | Description | Values |
|----------|-------------|--------|
| `icnste` | Enable constant redox potential | 0=off, 1=on |
| `ntcnste` | Steps between MC attempts | 5 |
| `solve` | Solvent redox potential (V) | e.g., 0.81 |
| `ered` | Redox potential reference | depends on system |

### CpHMD command-line flags
| Flag | Purpose |
|------|---------|
| `-cpin <file>` | Input protonation state definitions |
| `-cpout <file>` | Output protonation state history |
| `-cprestrt <file>` | Restart file (cpin format, use as next cpin) |

### C(E)pHMD command-line flags
| Flag | Purpose |
|------|---------|
| `-cein <file>` | Input redox state definitions |
| `-ceout <file>` | Output redox state history |
| `-cerestrt <file>` | Redox restart file |

### Titratable Residue Names
| Residue | PDB Name | Protonation States | Notes |
|---------|----------|-------------------|-------|
| ASP | AS4 | 5 (deprot + 4 protonated) | syn/anti on both oxygens |
| GLU | GL4 | 5 (deprot + 4 protonated) | syn/anti on both oxygens |
| HIS | HIP | 3 (diprotonated + HID + HIE) | HD1/HE2 tautomers |
| LYS | LYS | 3 | amino group |
| TYR | TYR | 2 | hydroxyl |
| CYS | CYS | 2 | thiol |
| Heme | HEH | 2 (oxidized/reduced) | bis-histidine heme |

### cphstats key flags
| Flag | Description |
|------|-------------|
| `-i <cpin>` | Input cpin file |
| `-o <file>` | Standard calcpka output |
| `-R <file> -r <N>` | Running average, window N |
| `--chunk <N>` | Chunk analysis, chunk size N |
| `--cumulative` | Cumulative average |
| `--populations <file>` | State populations per residue |
| `-c "RES:STATE,..."` | Conditional probability |
| `--fix-remd <prefix>` | Reorder pH-REMD cpout files |
| `--pKa` | Print pKa instead of fraction |
| `-p/-d` | Print protonated/deprotonated fraction |

## Worked Example

### CpHMD Explicit Solvent pKa Calculation

**Step 1:** Prepare system:
```bash
cpinutil.py -igb 2 -resnames AS4 GL4 -p protein.prmtop -op protein_adj.prmtop
cpinutil.py -p protein_adj.prmtop -igb 2 -o cpin
```

**Step 2:** Run production CpHMD at pH 4.0:
```
Constant pH MD, explicit solvent, pH=4.0
&cntrl
  imin=0, nstlim=5000000, dt=0.002,
  ntc=2, ntf=2, ntt=3, gamma_ln=2.0,
  temp0=300.0, ig=-1,
  icnstph=2, ntcnstph=100, ntrelax=200,
  solvph=4.0, saltcon=0.1,
  ntb=2, ntp=1, cut=8.0,
  ntwx=5000, ntpr=5000, ntwr=50000,
/
```
```bash
pmemd.cuda -O -i cph_pH4.in -o cph_pH4.out -p protein_adj.prmtop \
    -c eq.rst7 -cpin cpin -cpout pH4.cpout -cprestrt pH4.cprestrt
```

**Step 3:** Analyze:
```bash
cphstats -i cpin pH4.cpout -o pH4_results.dat
```

**Output:**
```
Solvent pH is    4.000
GL4 7   : Offset -0.448   Pred   3.552   Frac Prot 0.263 Transitions  91163
AS4 18  : Offset -1.063   Pred   2.937   Frac Prot 0.080 Transitions  41490
```

**Step 4:** Check convergence with running averages:
```bash
cphstats -i cpin pH4.cpout -r 1000000 -R running.dat -p
```

## Key Takeaways

1. **`icnstph=1`** for implicit solvent CpHMD, **`icnstph=2`** for explicit solvent. The cpin file is always required via `-cpin`.
2. **Reference energies** are pre-computed for model compounds (ACE-X-NME) using ff99SB + igb=2 + saltcon=0.1. If you change force field or GB model, you must re-derive them with `finddgref.py`.
3. **Explicit solvent CpHMD** requires adjusting GB radii for carboxylate oxygens (use `cpinutil.py -op`), and setting `ntrelax` for solvent relaxation after protonation changes.
4. **cphstats** provides cumulative, running, chunk averages, populations, and conditional probabilities. Always use `--fix-remd` before analyzing pH-REMD data.
5. **Constant Redox Potential** follows the same pattern as CpHMD: use `icnste=1`, `cein`/`ceout` files, `cestats` for analysis, and `source leaprc.conste` for setup.
